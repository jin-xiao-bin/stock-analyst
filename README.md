# Stock Analyst · AI 驱动的股票分析模拟交易平台

> ⚠️ **免责声明**：本项目所有交易均为**模拟交易**，仅供 交易学习和研究，不构成任何投资建议。

一个全链路 AI 驱动的 A 股研究练习平台：

- 📊 **多 Agent 投研报告**：数据建模（区分公司披露/分析假设/判断）→ 技术/基本面/舆情三路并行 → 首席交易员汇总，SSE 流式生成
- 💬 **人机协同分析**：与报告对话讨论，你的判断自动融合进"人机综合分析"，归纳总结复盘"你和 AI 谁看得准"
- 🤖 **自主决策 Agent**：盘中巡逻 + 收盘深度双路径决策，纯代码风控闸门（R1-R9 九条规则含组合级），thesis 失效条件自动跟踪
- 📈 **策略中心**：手写 / 导入 / AI 联网生成 / **聚宽策略适配**，沙箱安全执行，**参数寻优+过拟合诊断**，回测**基准对比线**，挂机自动交易，对话式策略修改
- ⏪ **历史回放练习**：防未来函数裁剪，T+1 / 涨跌停 / 佣金印花税仿真撮合，可挂策略对比，**多账户切换**
- 📱 **飞书双向**：重要事件推送 + 群内自然语言指挥买卖 + 消息利弊分析 + **多用户权限隔离**（admin/trader/viewer）
- 📅 **事件日历**：财报披露/限售解禁/除权除息自动跟踪，Agent 财报前自动规避开仓
- 📋 **每周投资周报**：飞书交互式卡片推送账户收益/最优决策/风险事件/学习笔记

## 功能架构

```
行情链(自愈同步+基准指数) · 回放链(多账户) · 分析链(人机融合+事件日历)
任务链 · 策略链(沙箱+聚宽适配+参数寻优+版本链) · 审查链(自回归优化)
自主决策链(R1-R9风控+组合级) · 账户链 · 飞书多用户权限链
```

技术栈：**Python 3.11+ / FastAPI / SQLAlchemy / pytest** · **Vue3 / Vite / TypeScript / Element Plus / klinecharts** · **MySQL**（必需）· Milvus + bge-m3 / Redis（可选降级）· DeepSeek / 博查 / Tushare / 东财

## 🚀 快速部署

### 1. 环境要求

| 组件 | 版本 | 必须 | 说明 |
|---|---|---|---|
| Python | ≥ 3.11 | ✅ | |
| Node.js + pnpm | ≥ 18 / ≥ 8 | ✅ | 前端构建 |
| MySQL | ≥ 8.0 | ✅ | 核心业务库 |
| Milvus | 任意 | ❌ | 不装自动降级（报告向量检索跳过） |
| Redis | 任意 | ❌ | 不装自动降级（直查 MySQL） |
| bge-m3 模型 | — | ❌ | 不配则向量功能降级 |

**需要的 API Key**：
- [DeepSeek](https://platform.deepseek.com)（必须——LLM 分析/决策）
- [Tushare Pro](https://tushare.pro)（必须——行情/财务/事件日历数据）
- [博查](https://bocha.ai)（可选——新闻搜索，不配走东财公开接口）
- [飞书开放平台](https://open.feishu.cn)（可选——通知/指令/多用户）

### 2. 克隆与后端

```bash
git clone <仓库地址>
cd stock-analyst/backend

# 安装依赖
pip install -r requirements.txt

# 配置密钥
cp ../.env.example .env    # Windows: copy ..\.env.example .env
# 编辑 .env 填入 MYSQL_URL / TUSHARE_TOKEN / DEEPSEEK_API_KEY 等

# 创建数据库
mysql -uroot -p -e "CREATE DATABASE IF NOT EXISTS stock_analyst DEFAULT CHARACTER SET utf8mb4"

# 启动
python -m uvicorn app.main:app --host 127.0.0.1 --port 8300

# 可选：预置沪深300数据（消除冷启动等待，约10分钟）
python scripts/preload.py

# 可选：初始化飞书 admin（开通指令权限后运行）
python scripts/init_admin.py <你的open_id> <你的名字>

# 运行测试（38个用例）
python -m pytest tests/ -v
```

### 3. 前端

```bash
cd ../frontend
pnpm install
pnpm run dev          # 打开 http://localhost:5173
```

### 4. 飞书配置（可选）

1. **通知**：飞书群 → 添加「自定义机器人」→ Webhook 填入 `.env` 的 `FEISHU_WEBHOOK_URL`
2. **指令**：[开放平台](https://open.feishu.cn)创建自建应用 → 机器人能力 → `im:message` 权限 → 事件订阅选「长连接」订阅接收消息 → 发布 → App ID/Secret 填入 `.env`
3. **多用户**：群里@机器人发任意消息获取 open_id → admin 在群里执行 `添加用户 <open_id> <名字> [trader] [初始资金]`

### 5. 首跑体验路径

1. **行情页**：搜索 `000001` 看K线 + 实时报价 + 三种复权
2. **AI分析**：选股 → 生成分析（2-3分钟）→ 报告「讨论」标签发表观点 → 查看自动融合的人机综合分析
3. **回放交易**：新建回放（可关联已有账户）→ 逐日推进 → 手动买卖 → 挂策略对比
4. **策略中心**：AI生成或手写 → 「发起回测」（带沪深300基准线+超额收益）→ 「参数寻优」（网格+热力图+过拟合警告）→ 「对话」让 AI 改策略 → 导入聚宽策略
5. **自主决策**：配置股票池+风控（预设模板一键填充）→ 启动 → 飞书群查看每日决策摘要

### 6. 风控规则（R1-R9）

| 规则 | 说明 | 默认 |
|---|---|---|
| R1 | 单票仓位上限 | 30% |
| R2 | 日内最大交易次数 | 5次 |
| R3 | 回撤熔断（暂停开仓N日） | 15%/10天 |
| R4 | 连续亏损降频 | 5笔 |
| R5 | 同股冷却期 | 1天 |
| R6 | 股票池白名单 | — |
| R7 | **财报前禁开仓** + **行业集中度≤40%** | 3天/40% |
| R8 | 分散度告警 | ≥3只 |
| R9 | **账户级独立熔断** | 20% |

### 7. 每日自动任务（后端内置调度）

| 时间 | 任务 |
|---|---|
| 交易时段每小时 | Agent 盘中巡逻决策（实时价成交） |
| 15:30 | Agent 收盘深度决策 |
| 17:10 | 行情增量同步（+启动追补+查询自愈三重保障） |
| 17:15 | 事件日历同步（财报/解禁/除权） |
| 17:30 | 观察任务核验 |
| 17:45 | 挂机策略执行 |
| 周日 18:00 | Agent 学习笔记生成 |
| 周日 19:00 | **飞书投资周报**（交互式卡片） |

### 8. 聚宽策略导入

支持直接粘贴聚宽策略代码（`.py` 或 `.ipynb` Notebook JSON）：
- 自动套聚宽兼容层（attribute_history/order_target 等 API 桥接）
- 兼容层失败时 AI 自动改写兜底
- 多股票策略简化为单标的运行

## 已知限制

- 分钟级数据不可用（数据源限频），全系统为日级 + 实时快照
- A股专用（代码归一化、涨跌停规则）
- 多用户鉴权仅覆盖飞书通道（Web界面暂无登录）
- 多标的组合策略（开发中，见路线图 P1-1）
